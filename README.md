
# Customer Churn Analysis

## Project Overview
This project analyzes customer churn patterns using Python, SQL, and Tableau.

## Tools Used
- **Python** — Data Cleaning & Preprocessing
- **SQL** — Data Querying & Analysis
- **Tableau Public** — Interactive Dashboard & Story

## Workflow
Raw Data → Python (Clean) → SQL (Query) → Tableau (Visualize)

## Key Insights
- Total Customers: 7,043
- Total Churned: 1,869
- Churn Rate: 26.54%
- Avg Monthly Charges: $64.76
- Month-to-month contract customers churn more
- Fiber optic users have highest churn rate
